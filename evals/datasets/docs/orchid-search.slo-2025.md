# orchid-search service level objectives (2025 revision)

> Superseded. Retained for audit history only; the current objectives live in

## Latency

The p99 request latency objective for orchid-search was 750 milliseconds.
This figure was relaxed in the following planning cycle after the replicator
rewrite reduced tail latency.
